# 王嘉宇补充说明

## 本次调整汇总

### 1. 技能卡频率下调

- 技能卡目标数量由 `40` 调整为 `24`
- 技能刷新间隔由 `4.0s` 调整为 `8.0s`

### 2. 野兽模式障碍上限

- 障碍最大数量由 `5` 调整为 `35`

### 3. 野兽模式撞障碍规则

- 撞到障碍后不再直接死亡
- 每次碰撞减少 `1` 节身体长度
- 对应的长度型视野增幅会随之下降
- 被撞到的障碍会立刻消失

### 4. 输入兼容性修复

- 经典模式与野兽模式的核心按键都改为“物理键位 + 常规键值”双判断
- 现在在中文输入法开启时，`WASD / Q / R / M / 1 / 2 / 空格 / ESC` 仍可正常使用
- 大写锁定开启后也不会影响这些按键

### 5. 视野与技能调整

- 视野成长上限由 `1.25x` 提高到 `1.5x`
- 新增技能卡 `vision`
  - 效果：把当前视野倍率临时提升到 `2.0x`
  - 持续时间：`5s`
- 五种技能现在都有独立的圆形彩色边框

当前技能列表：

- `purge`
- `haste`
- `harvest`
- `grow`
- `vision`

### 6. 野兽尺寸调整

- 野兽占位由 `3x3` 改为 `2x2`
- 对应贴图接口保留，不影响后续自行替换素材

### 7. 地图与刷新节奏调整

- 野兽模式地图由 `8000 x 8000` 扩大到 `16000 x 16000`
- 食物目标数量由 `200` 提高到 `400`
- 食物刷新间隔由 `3.0s` 提高到 `1.5s`
- 技能卡没有跟随地图扩张而增多，而是继续按“更稀有”的方向下调

## 当前贴图接口

### 野兽贴图目录

```text
assets/sprites/beasts/
```

文件名固定为：

- `wolf.png`
- `boar.png`
- `bear.png`

建议：

- 使用透明背景 PNG
- 使用正方形画布
- 推荐尺寸 `512x512` 或更高

程序会自动把它们缩放到地图中的 `2x2` 占位。

### 技能贴图目录

```text
assets/sprites/skills/
```

文件名固定为：

- `purge.png`
- `haste.png`
- `harvest.png`
- `grow.png`
- `vision.png`

建议：

- 使用透明背景 PNG
- 使用正方形画布
- 推荐尺寸 `256x256` 或更高

同一张技能图会同时用于：

- 地图中的技能卡
- 左下角已持有技能图标

如果暂时没有放入图片，游戏会显示圆形占位图，不会报错。
