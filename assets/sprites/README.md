# 贴图放置说明

游戏已经为野兽和技能图标预留了直接读取 PNG 的接口。

## 1. 野兽贴图

把图片放到：

```text
assets/sprites/beasts/
```

文件名固定为：

- `wolf.png`
- `boar.png`
- `bear.png`

建议：

- 透明背景 PNG
- 正方形画布
- 推荐尺寸 `512x512` 或更高

程序会自动把它们缩放到地图中的 `3x3` 格占位。

## 2. 技能贴图

把图片放到：

```text
assets/sprites/skills/
```

文件名固定为：

- `purge.png`
- `haste.png`
- `harvest.png`
- `grow.png`

建议：

- 透明背景 PNG
- 正方形画布
- 推荐尺寸 `256x256` 或更高

程序会自动把同一张技能图同时用于：

- 地图上的技能卡
- 左下角已持有技能图标

## 3. 替换方式

只需要直接覆盖同名 PNG 文件，然后重新运行游戏即可，不需要改代码。

如果目录中没有对应图片，游戏会显示占位图，方便你后续逐步补素材。
