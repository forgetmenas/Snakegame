# 贪吃蛇双模式

项目包含两个可切换玩法，并且启动后会以当前屏幕原生分辨率全屏运行。适配的是游戏内画面布局，不是把整张游戏画面强行拉伸。

## 运行方式

建议在你的 `conda` 环境中运行：

```bash
conda activate snakegame
pip install -r requirements.txt
python run.py
```

## 初始界面

进入游戏后，点击界面中的 `1` 或 `2` 选择模式，也支持键盘 `1` / `2`。

主要操作按键已经兼容：

- 英文键盘
- 中文输入法开启状态
- 大写锁定开启状态

## 模式说明

### 1. 经典模式

- 使用 `WASD` 或方向键控制。
- 地图铺满当前屏幕，并带有轻量随机障碍。
- 食物和障碍分布每局随机变化。
- `Q` 打开暂停菜单；游戏中按 `R` 重开，暂停时按 `R` 继续，`M` 返回菜单，`ESC` 直接退出。

### 2. 野兽模式

- 地图尺寸已经再次扩大到原来的两倍。
- 鼠标左键点击地图后，蛇会自动游走到目标点；不操作则静止。
- 点击超出地图边界的位置时，蛇只会贴边运行，不会出界。
- 迷雾只保留蛇头可见区域。
- 视野按长度成长：每比初始长度多 `1` 节，视野倍率增加 `0.05`，最高 `1.5x`。
- 存在临时视野强化技能，可把视野短暂提升到 `2.0x`，持续 `5s`。
- 食物刷新速度已进一步提高。
- 随机会生成零星障碍，最多 `35` 个，每个 `30s` 后自行消失。
- 撞到障碍后不会直接死亡，而是减少 `1` 节身体，并立即清除该障碍。
- 边界用红色高亮标注。
- 野兽占 `2x2` 格，技能卡占 `1x1` 格。
- `空格` 释放当前技能，`Q` 打开暂停菜单；游戏中按 `R` 重开，暂停时按 `R` 继续，`M` 返回菜单，`ESC` 直接退出。

## 技能列表

- `purge`：清除当前可见区域内的全部野兽。
- `haste`：获得 `5s` 加速。
- `harvest`：吸收当前可见区域内的全部食物。
- `grow`：立刻增加 `1` 节身体。
- `vision`：把当前视野倍率临时提升到 `2.0x`，持续 `5s`。
