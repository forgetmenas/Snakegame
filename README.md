# 迷雾贪吃蛇 - Fog of War Snake

在迷雾中探索、捕食、生存的贪吃蛇游戏。

## 运行方式

```
pip install -r requirements.txt
python run.py
```

## 初始界面

进入游戏后，点击界面中的 `1` / `2` / `3` 选择模式，也支持键盘数字键或直接点击卡片。

## 模式说明

### 1. 经典模式

- 使用 `WASD` 或方向键控制。
- 地图铺满当前屏幕，并带有轻量随机障碍。
- 食物和障碍分布每局随机变化。
- `Q` 打开暂停菜单；游戏中按 `R` 重开，暂停时按 `R` 继续，`M` 返回菜单，`ESC` 直接退出。

### 2. 野兽模式（单人）

- 鼠标左键点击地图后，蛇会自动游走到目标点；不操作则静止。
- 点击超出地图边界的位置时，蛇只会贴边运行，不会出界。
- 视野按长度成长：每比初始长度多 `1` 节，视野倍率增加 `0.05`，最高 `1.5x`。
- 随机会生成零星障碍，最多 `35` 个，每个 `30s` 后自行消失；撞到障碍后不会直接死亡，而是减少 `1` 节身体，并立即清除该障碍。
- 饥饿惩罚：饱食度降为 `0` 后，每走 `5` 格丢失 `1` 节身体（可致死）。撞障碍与饥饿惩罚同帧触发时只算一次。
- 野兽占 `2x2` 格（4种野兽等概率出现），技能卡占 `1x1` 格。
- `空格` 释放当前技能，`Q` 打开暂停菜单；`R` 重开，`M` 返回菜单，`ESC` 退出。

### 3. 野兽对战（双人 vs AI）

- 操作方式与野兽单人模式相同，场上同时存在一条 AI 蛇。
- AI 蛇速度为玩家的 `0.75` 倍，会主动觅食并尝试攻击玩家。
- 蛇咬规则：A 蛇头碰到 B 蛇身体时，B 从碰撞部位到蛇尾全部消除（撞到头则保留头，其余消除），同时 A 死亡并进入 `3s` 复活倒计时，复活后恢复初始状态。
- 对方蛇可见性：默认隐藏在迷雾中；吃到食物后对方可见 `5s`，对方复活后可见 `5s`；在自身视野范围内时正常显露。
- 玩家最大视野倍率为 `2.0x`；食物和技能刷新速度更快；障碍上限 `75` 个，每 `30s` 刷新位置。
- 游戏结束条件：被野兽吃掉 / 身体一节不剩时撞障碍或饥饿致死。
- `Q` 暂停后选择返回主界面时，显示当前身体节数多者获胜；结果页按 `R` 重开，`M` 返回菜单。

## 技能列表

- `purge`：清除当前可见区域内的全部野兽。
- `haste`：获得 `5s` 加速。
- `harvest`：吸收当前可见区域内的全部食物。
- `grow`：立刻增加 `1` 节身体。
- `vision`：把当前视野倍率临时提升到 `2.0x`，持续 `5s`。
